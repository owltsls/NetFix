## 1. 它能做什么

NetFix 针对 Windows 上一类常见又难排查的问题：**浏览器打不开网页，但微信、QQ、下载器等其他软件却能正常上网**。根因通常是代理配置残留——系统代理开关被打开，指向一个已经退出的代理软件端口（如 `127.0.0.1:7897`），浏览器把请求都发给这个"死代理"，自然全部失败。

它的核心能力：

- **8 通道只读体检**：一次性扫描 WinINET 系统代理、WinHTTP、环境变量代理、DNS、hosts、网卡、常见代理端口、浏览器代理痕迹，异常项高亮并给出判断依据。
- **修复前自动快照**：把 Internet Settings、环境变量、hosts、DNS/WinHTTP 配置导出到 `%LOCALAPPDATA%\NetFix\backup\`，全程可回滚。
- **分项勾选修复**：6 项修复可自由勾选（关系统代理、重置 WinHTTP、清环境变量、刷 DNS、重置 Winsock/TCP-IP、清理回环 DNS），高风险项默认不勾选。
- **修复后自检与回滚**：自动做 DNS 解析 + HTTPS 访问自检，确认是否真的恢复；不满意可一键回滚到修复前状态。
- **诊断报告导出**：把体检结果、修复记录导出为可汇报的 HTML 报告。

## 2. 界面预览

工具采用三页式向导。完整低保真线稿见 [`wireframes/index.html`](wireframes/index.html)（浏览器打开即可查看，含 P-01 体检页 / P-02 修复确认页 / P-03 结果回滚页三个画板与页面流转图）。

- **P-01 网络健康体检**：只读扫描 8 条通道，红/黄/绿状态一目了然，每项可点"依据"查看判断理由，并内置"为什么浏览器断网其他软件正常"的知识说明。
- **P-02 确认修复**：修复前自动生成快照，勾选需要的项目（风险项默认不选）。
- **P-03 结果与回滚**：连通性自检结果、修复记录、一键回滚、导出报告。

## 3. 快速开始

### 方式 A：直接运行打包版（推荐）

1. 到本仓库 Releases 下载 `NetFix.exe`（发布后提供）。
2. 双击运行，无需安装。**体检是只读的，可放心点击。**
3. 修复中涉及 Winsock/TCP-IP 重置的项目需要管理员权限，点工具里的"以管理员身份重启"提权后再修复。

### 方式 B：从源码运行

```bash
# 需要 Python 3.10+（开发与验证环境：Python 3.13）
pip install PySide6
cd src
python netfix_gui.py
```

> 当前验证依赖版本：Python 3.13.14 · PySide6 6.12.0 · PyInstaller 6.22.3。

## 4. 使用流程

1. **一键体检**：点"一键体检"，等待 8 通道扫描完成，异常项以红色/黄色标记；点每行"依据"查看具体配置值。
2. **下一步选修复**：进入修复页，工具会先创建配置快照。默认只勾选推荐项；Winsock 重置、回环 DNS 清理等风险项需你手动勾选，且需要管理员权限。
3. **确认修复**：点"确认修复（先备份）"，工具先备份再逐项执行，实时显示进度与结果。
4. **看自检与回滚**：修复后自动做 DNS + HTTPS 自检；若未恢复或想还原，点"一键回滚"从快照恢复，或点"导出报告"保存诊断结果。

## 5. 为什么会这样

Windows 有 4 套互相独立的上网通道：

| 通道 | 谁在读它 |
| --- | --- |
| ① WinINET 系统代理 | Edge/Chrome 等浏览器 |
| ② WinHTTP | 系统更新、部分后台服务 |
| ③ 环境变量代理 | git / npm / python / curl |
| ④ 软件自带 socket | 微信 / QQ / Steam 等直连 |

故障只落在某一条通道时，就会出现"这家断网、那家正常"。典型场景：代理/加速器软件退出或卸载后，**系统代理开关没还原**，仍指向一个无人监听的本地端口——浏览器请求全部失败，而其他软件直连外网照常工作。详见 [`docs/诊断报告-浏览器断网.md`](docs/诊断报告-浏览器断网.md)。

## 8. 技术要点

- **纯标准库 + PySide6**：体检逻辑用 `winreg` / `ctypes` / `subprocess` 调用 Windows API 与 `netsh`、`reg`、`ipconfig` 命令，无需额外系统依赖。
- **稳健中文编码**：针对中文 Windows 命令输出，做了 cp936 → GBK → UTF-8 的多级解码回退，避免乱码导致误判。
- **先备份后修改**：任何修复前都导出注册表与 hosts 快照到 `%LOCALAPPDATA%\NetFix\backup\`，回滚按快照精确恢复。
- **最小侵入原则**：默认不改 hosts、防火墙、Wi-Fi 密码；风险项默认不勾选。
- **高对比度界面**：全局 QSS + 对象名统一配色，正文对比度 ≥ 4.5:1。
